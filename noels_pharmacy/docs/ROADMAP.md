# Release scope and later extensions

## Included in 19.0.1.0.0

- Core patient, prescription, refill, alert, dispensing, label, register and audit engine
- Native Sales connector
- Native POS Actions prescription popup and payment gate
- Website/eCommerce upload and customer history
- Inspection PDF, separate CSV register pack and patient history PDF
- Static validation, automated transaction tests and Cloudpepper deployment documentation

## Sensible later extensions

- Licensed drug knowledge database import/synchronisation
- CDAP or other national programme support
- Insurer eligibility and claims
- Electronic prescription integration
- Refill reminder automation
- Barcode label-printer profiles for specific hardware
- Two-person witness workflow for selected controlled/narcotic events
- Stock receipt/adjustment register integration if required by the local regulator

These are intentionally outside the first release so the dispensing workflow stays simple and the core remains upgradeable.
